# Extract Hard Lineage Assignments from Slingshot

Extract Hard Lineage Assignments from Slingshot

## Usage

``` r
extract_slingshot_assignments(sce, path_prefix = "Path")
```

## Arguments

- sce:

  A SingleCellExperiment with Slingshot results.

- path_prefix:

  Prefix for lineage labels.

## Value

A list with pseudotime and lineage assignment metadata.
