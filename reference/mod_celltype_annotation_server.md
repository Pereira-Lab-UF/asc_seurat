# Automated Cell-Type Annotation Module - Server

Automated Cell-Type Annotation Module - Server

## Usage

``` r
mod_celltype_annotation_server(
  id,
  seurat_obj_single = NULL,
  seurat_obj_multi = NULL
)
```

## Arguments

- id:

  Module namespace ID.

- seurat_obj_single:

  Optional reactive Seurat object from the single-sample workflow.

- seurat_obj_multi:

  Optional reactive Seurat object from the integration workflow.
