# Open a Graphics Device

Opens a graphics device with cm-based sizing.

## Usage

``` r
open_plot_device(file, format = "png", width = 15, height = 10, dpi = 300)
```

## Arguments

- file:

  Character. Output file path.

- format:

  Character. One of "png", "tiff", "jpeg", "pdf", "svg".

- width:

  Numeric. Width in cm.

- height:

  Numeric. Height in cm.

- dpi:

  Integer. Resolution in DPI.
