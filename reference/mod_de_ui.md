# Differential Expression Module — UI

Differential Expression Module — UI

## Usage

``` r
mod_de_ui(id, allow_conserved = FALSE, step_number = 5)
```

## Arguments

- id:

  Module namespace ID.

- allow_conserved:

  Logical. Whether to expose conserved-marker analysis.

- step_number:

  Numeric step number to show in the workflow title.
