# Clustering Module - UI

Clustering Module - UI

## Usage

``` r
mod_clustering_ui(
  id,
  step_number = 4,
  download_label = "Download Clustered Object",
  tsne_option = TRUE
)
```

## Arguments

- id:

  Module namespace ID.

- step_number:

  Numeric step number to show in the workflow title.

- download_label:

  Character label for the clustered object download.

- tsne_option:

  Logical. Show the option to also compute tSNE (single-sample workflows
  only).
