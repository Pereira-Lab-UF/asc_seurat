# Advanced Plots Module — Server

Advanced Plots Module — Server

## Usage

``` r
mod_advanced_plots_server(
  id,
  seurat_obj_single = NULL,
  seurat_obj_multi = NULL
)
```

## Arguments

- id:

  Module namespace ID.

- seurat_obj_single:

  Reactive Seurat object from single-sample pipeline.

- seurat_obj_multi:

  Reactive Seurat object from integration pipeline.
