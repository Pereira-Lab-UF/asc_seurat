# ascseurat: Analytical Single Cell Seurat-Based Web Application

Asc-Seurat (Analytical Single Cell Seurat-Based Web Application) is an
interactive Shiny application for the analysis of single-cell RNA
sequencing (scRNA-seq) data. It provides a guided, step-by-step
interface for quality control, normalization, clustering, differential
expression, trajectory inference, and cell-type annotation, all powered
by the Seurat v5 framework.
